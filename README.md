# Taller de confecciones

## Compilar módulos de apoyo
```bash
elixirc datos.exs util.exs validacion.exs liquidacion.exs reportes.exs
```

## Ejecutar programa
```bash
elixir programa.exs
```

## Ejecutar mediciones C.3
```bash
elixir mediciones.exs
```

No se usan `mix`, librerías externas, `File`, procesos, structs, recursividad ni `try/rescue` para validación.
